# Reset Your Password
!!! Roles "User roles" 
    Authenticated user

1. On the log in page, Select "Reset your password"
![The login page with the reset your password button highlighted](../_embeds/reset-password-01.png)

2. Enter your username or email address and select "submit"
![The login page with the username or email address field filled out. The submit button is highlighted](../_embeds/reset-password-02.png)

3. The homepage will load and display a success message. Password reset instructions will be sent to your email address.
![The home page with a success message displayed.](../_embeds/reset-password-03.png)
