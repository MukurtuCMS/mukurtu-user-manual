# Privacy and Security

Privacy and security will depend on various factors such as host/server set up. Drupal 11 (the software upon which Mukurtu is built) also releases regular security updates and patches. Here are proactive actions you can take to make your Mukurtu site and content more secure:

1) Check with your host to see what security measures they have in place.

2) Make sure your site and modules are up to date. 

- [Check for Database and Module Updates](../infrastructure/CheckForUpdates.md)

3) Consider using a CAPTCHA module to prevent spam accounts.

3) You can also prevent visitors from making their own user accounts. 

- [Manage User Account Registration](../users/manage-user-account-registration.md)

4) Consider using strict protocols for any items that are sensitive in nature, or keeping them offline altogether.

- [Understanding Communities and Cultural Protocols](../3Cs/UnderstandingCommunitiesAndCulturalProtocols.md#cultural-protocol-types)


5) Make sure users are assigned to appropriate user roles:

- [User Roles](../users/user-role-types.md) 
- [Manage User Accounts Site-wide](../users/manage-user-accounts-site-wide.md)
- [Manage Community Membership and Roles](../3Cs/ManageCommunityMembershipAndRoles.md)
- [Manage Protocol Membership and Roles](../3Cs/ManageProtocolMembershipandRoles.md)
