# Overview of Hosting Options 

There are several options for hosting a Mukurtu site: third-party hosting, self-hosting, and Mukurtu Hosting.

## Third-party Hosting

This option is ideal for users with limited funds and technical resources. Mukurtu 4 is built on Drupal 11, and any hosting provider that can run a Drupal site should be able to run a Mukurtu site. It's a good idea to confirm this with the provider before paying for hosting.

We have worked directly with [Reclaim Hosting](https://www.reclaimhosting.com/) to create a Mukurtu installation package. Reclaim offers easy installation and maintenance of Mukurtu sites (as well as many other services and platforms) at affordable rates ($132/year for 100GB of storage at the time of this writing). We consider Reclaim Hosting a trusted vendor.

We are also working to make Mukurtu available through Installatron, which would enable easy install with hosting providers who use it, though we cannot make any recommendations as to the reliability of those providers.

## Self-Hosting

Self-hosting is an viable option for organizations with an IT department with Drupal experience who can run and maintain their own servers. This can provide enhanced security and control of your data.

See [System Requirements](../infrastructure/SystemRequirements.md) for a basic overview of Drupal 11 system requirements. For greater detail, see [Drupal's System Requirements](https://www.drupal.org/docs/getting-started/system-requirements/overview#s-drupal-11-and-drupal-cms)

All of the source code and system requirements to run a Mukurtu CMS site are available through our [GitHub repository](https://github.com/MukurtuCMS/mukurtucms#self-hosted).

If your IT department is not comfortable with the server requirements, or you do not have a department that can run the necessary equipment, you may want to consider a hosted site.

If your IT department has any questions about server requirements or installation, they can contact us at [support@mukurtu.org](mailto:support@mukurtu.org)

## Mukurtu Hosting

Finally, the Mukurtu Team now offers hosting services in response to long term community requests for a trusted hosting provider that is familiar with the inner workings of Mukurtu CMS. This also enables us to provide more dedicated support for those projects using our hosting services. Hosting packages begin at $1200/yr for 50GB of storage. To read more about available packages, visit [Mukurtuhosting.org](https://www.mukurtuhosting.org/services-and-pricing and contact us at https://www.mukurtuhosting.org/contact)

Mukurtu CMS will continue to be free and open source. This is just one option for hosting among many and is in no way required.
