# System Requirements

To run a Mukurtu CMS 4.0 (or above) instance, the minimum system requirements are: 

A web server that supports PHP such as Apache or Nginx  

If using Apache make sure: 

- the mod_rewrite module is enabled 

- you have the ability to use local .htaccess files 

- PHP-FPM OR mod_php must be installed 

If using Nginx 

- PHP-FPM must be installed 

- Create nginx config for Drupal and PHP (Google AI is helpful for this) 

PHP version 8.3 or higher. Version 8.4 is recommended 

A database server such as  

- [MySQL 5.7.8](https://www.mysql.com/) or higher 

- [MariaDB 10.3.7](https://mariadb.org/) or higher 

Experience installing and maintaining Drupal servers is strongly recommended. 

Full documentation is available at [http://github.com/MukurtuCMS/mukurtucms](http://github.com/MukurtuCMS/mukurtucms).
