# Customize Site Navigation

!!! roles "User roles"
    Drupal administrator, Mukurtu Manager

1. To customize your site's main menus, navigate to the **Structure** link in your left-hand sidebar, then select **Menus**. Navigate to **Main navigation** and select the "Edit menu" button. You can also navigate directly to `/admin/structure/menu/manage/main`.
