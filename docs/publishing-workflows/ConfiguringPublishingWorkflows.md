# Configuring Publishing Workflows

!!! roles "User roles" 
    Mukurtu manager

Mukurtu ships with two ready-to-use publishing workflows: the [default content workflow](UsingDefaultWorkflow.md) and the [editorial workflow](UsingEditorialWorkflow.md). A Mukurtu manager chooses which one is active for the whole site, and can also create custom workflows if neither built-in option fits. 

## Choose the active workflow

1. From your **Dashboard**, under **Publication Tools**, select **Publishing workflow**.
2. Select the radio button next to the workflow you want to activate.
3. Select "Save".

!!! warning
    Only one workflow can be active at a time, and it applies to every content type across the site. You cannot use the default workflow for some content types and the editorial workflow for others.

## Create a custom workflow

If neither built-in workflow fits your community's needs, you can create your own.

1. Select "Create new workflow".
2. Give your workflow a *Workflow name*, then add the states and transitions your process requires.
3. Select "Save".

Your new workflow appears in the list on the publishing workflow settings page, where you can make it active.

!!! tip
    You can also duplicate an existing workflow, including the default or editorial workflow, as a starting point for a custom one. Select "Duplicate" from the actions menu next to the workflow you want to copy.

## Edit or delete a workflow

!!! requirement
    The default and editorial workflows that ship with Mukurtu cannot be edited or deleted directly. To make changes, duplicate one of them first.

Custom workflows can be edited or deleted from the publishing workflow settings page using the actions menu next to the workflow.
