# Using the Editorial Content Workflow

!!! roles "User roles" 
    Mukurtu manager, Protocol steward, Language steward, Contributor, Curator, Language contributor

The editorial workflow adds a review step before content is published, so a protocol or language steward can check content before it becomes visible. For an overview of its states and transitions, see [Understanding Publishing Workflows](UnderstandingPublishingWorkflows.md).

## Submit content for review

While creating or editing content, select "Submit for Review" to send it to the review queue instead of publishing it directly. You can also select "Save as Draft" to keep working on it privately before submitting.

Content you've submitted stays listed under your **Dashboard**, in **My Content > In Progress**, until a steward reviews it.

## Review submitted content

!!! roles "User roles" 
    Protocol steward, Language steward

Stewards review content from the **Review Queue**, found under your **Dashboard**.

!!! tip
    Language stewards only review dictionary words and word lists. Protocol stewards review all content types within the protocols they steward.

To review an item:

1. Select the item from the **Review Queue** to open it.
2. Read the item's review history, if any, in the review panel below the title.
3. Choose a transition, such as "Publish", "Needs Edits", or "Archive", and add an optional note explaining your decision.
4. Select "Save".

Your note and the state change are recorded in the item's review history, so contributors can see what changed and why.

## Respond to review feedback

If a steward selects "Needs Edits", the content moves to the **Edits Needed** state and returns to you. To resubmit it:

1. Open the item and make the requested changes.
2. Select "Resubmit for Review".

The item returns to the review queue for another look.

## Archive and restore content

!!! roles "User roles" 
    Mukurtu manager, Protocol steward, Language steward

Archiving removes published content from public view without deleting it.

- To archive published content, open the item and select "Archive".
- To bring archived content back as a draft, open the item and select "Restore to Draft".
- To send published or archived content back for another review, select "Return to Review".

## Bulk actions

From the content overview page, stewards and Mukurtu managers can select multiple items and apply "Publish", "Archive", or "Restore to Draft" to all of them at once. Submitting for review, requesting edits, resubmitting, and returning to review are not available as bulk actions; these are done one item at a time from the review panel.
