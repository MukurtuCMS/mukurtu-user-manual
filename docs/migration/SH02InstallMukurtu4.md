# Install Mukurtu 4

We recommend familiarizing yourself with the Drupal 11 installation process before beginning the Mukurtu 4 installation. The [Drupal 11 Installation Guide](https://www.drupal.org/docs/installing-drupal) provides a good overview of the process, and the recommended system settings are a good starting point for Mukurtu as well.

If installing directly on a web host that has a command line interface, you can [install Mukurtu via composer](https://github.com/MukurtuCMS/Mukurtu-CMS#installing-mukurtu-cms-with-composer).

Ensure that the [post-installation steps](https://github.com/MukurtuCMS/Mukurtu-CMS#post-installation-steps) are completed as well, as the migration tool will not operate properly without them.
