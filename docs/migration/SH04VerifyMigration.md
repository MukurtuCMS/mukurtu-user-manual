# Verify Migration and Site Operation

Provided there were no migration errors that needed to be addressed, the next step is to spend some time using the site and ensuring that content, users, media, etc. has migrated properly. You likely do not want to review every possible page, but conduct as much of a test, with as many users, as you feel is necessary.
