# Clear Caches

!!! Roles "User roles" 
    Administrator, Mukurtu manager

A common troubleshooting technique is to manually clear Drupal caches. 

As an Administrator or Mukurtu manager in the Drupal menu bar, select the "Rebuild Cache" button.

![The homepage with the development menu open and cache clear highlighted](../_embeds/cache-clear-01.png)

It may take a few minutes to run. When complete, the page will reload and an “All caches cleared” confirmation message will display.

![The homepage reloaded with a success message](../_embeds/cache-clear-02.png)
