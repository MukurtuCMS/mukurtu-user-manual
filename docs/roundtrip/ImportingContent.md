# Importing Content

!!! Roles "User roles" 
    TBD

- In Mukurtu 3, there were many different starting points for import, depending on the content type or media being import, or if importing multiple content types/media. 
    - Metadata of a single content type went straight to an upload form with no configuration options.
    - Including multiple components required quite complex interrelated spreadsheets and media files properly arrange in zipped folders.
- Now there is more flexible single import start point that can handle more complexity.
- Note that there may be other bespoke importers for specific cases, like basic dictionary words.

## Upload files

- All imports now start at `/admin/import` (linked on dashboard).
- Any combination of CSV sheets and supported media assets can be selected.

At this point in the process, we run into errors.
