# Understanding Media Uploads

!!! roles "User roles"
    Protocol steward, contributor, community record steward, curator, language steward, language contributor 

Mukurtu supports different types of media, including audio files, SoundCloud links, documents, external embeds, image files, remote video, and video files. Most media types have unique metadata fields and other requirements to add them to your media library. These articles provide step-by-step instructions on how to upload each media type.

Media can be uploaded from your dashboard, your left-hand sidebar, or when adding content. These articles focus on uploading media from your dashboard. Instructions on for uploading media when you create content can be found in the articles on creating content.
