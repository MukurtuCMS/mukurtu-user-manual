# Understanding Search and Browse

Mukurtu features a full-text search and multiple browse options to help users discover content. 

The simplest way to search for content is by using the Search box on any of the Browse pages. 

On the Browse and Browse Digital Heritage pages, site users can refine their search results using the taxonomy fields on the right-hand sidebar.

On the Dictionary Browse page, users can refine their search by Language, Community, Cultural Protocol, Content Type, or by filtering out Word Lists. Users can also choose to sort by Glossary order or Search relevance. 

To help users find specific content in multipage items or community records, you can select the toggle by Show all pages and Show community records.
